# JSON Developer — store listing

## en-US

**Title (≤30):** JSON Developer Watch Face

**Short description (≤80):** Your day as pretty-printed JSON. Syntax colors, real data, AOD and presets.

**Full description:**

Your watch, pretty-printed. JSON Developer turns the time and your daily stats into a clean, syntax-highlighted
JSON document — designed for developers who live in their editor.

{ "time": "14:35" } is always the hero of the screen, with your data organized as readable properties:
date, battery, steps, heart rate, weather, device status and any complication you choose.

PRESETS
• Clean JSON — just time and date
• Developer — time, date and essentials, with line numbers
• Full JSON — every indicator plus battery and step rings
• AMOLED — minimal lit pixels for maximum battery life
Start from a preset, then change any option individually.

DEEP CUSTOMIZATION
• 5 layouts: Minimal, Compact, Balanced, Full, Informative
• 4 JSON styles: pretty printed, line numbers, indent guides, bare
• Time: phone setting, 24 h, 12 h, 12 h + AM/PM, optional seconds, 4 clock sizes
• 10 date formats: DD/MM/YYYY, MM/DD/YYYY, ISO, weekday + date, full date and more
• Battery: percentage, progress bar, ring, icon or hidden
• Steps: count, steps/goal, goal bar, ring, icon or hidden
• Heart rate, weather (°C/°F) and device status lines
• Two complication lines for calories, distance or any data source on your watch
• Colors for keys, values, clock, punctuation and background — 11 editor palettes

REAL DATA ONLY
Values come from your watch. When a source has no data, JSON Developer shows null — never a fake number.

ALWAYS-ON DISPLAY
A dedicated, mostly black AOD that keeps the JSON look with fewer lit pixels and no seconds.

Made with Watch Face Format for Wear OS 5+. Optimized for Samsung Galaxy Watch 6 and round AMOLED screens.

## pt-BR

**Título (≤30):** JSON Developer Watch Face

**Descrição curta (≤80):** Seu dia em JSON formatado. Cores de sintaxe, dados reais, AOD e presets.

**Descrição completa:**

Seu relógio, formatado como código. O JSON Developer transforma a hora e as suas estatísticas do dia num documento
JSON limpo e com syntax highlighting — feito para quem vive no editor.

{ "time": "14:35" } é sempre o destaque da tela, com seus dados organizados como propriedades fáceis de ler:
data, bateria, passos, frequência cardíaca, clima, status do aparelho e as complicações que você escolher.

PRESETS
• Clean JSON — só hora e data
• Developer — hora, data e o essencial, com números de linha
• Full JSON — todos os indicadores com anéis de bateria e passos
• AMOLED — poucos pixels acesos para economizar bateria
Comece por um preset e ajuste qualquer opção individualmente.

PERSONALIZAÇÃO COMPLETA
• 5 layouts: Minimalista, Compacto, Equilibrado, Completo, Informativo
• 4 estilos de JSON: formatado, números de linha, guias de indentação, sem chaves
• Hora: padrão do celular, 24 h, 12 h, 12 h + AM/PM, segundos opcionais, 4 tamanhos
• 10 formatos de data: DD/MM/AAAA, MM/DD/AAAA, ISO, dia da semana + data, data completa e mais
• Bateria: percentual, barra, anel, ícone ou oculta
• Passos: quantidade, passos/meta, barra da meta, anel, ícone ou oculto
• Frequência cardíaca, clima (°C/°F) e status do aparelho
• Duas linhas de complicações para calorias, distância ou qualquer fonte do relógio
• Cores das chaves, valores, relógio, pontuação e fundo — 11 paletas de editor

SOMENTE DADOS REAIS
Os valores vêm do seu relógio. Sem dado disponível, aparece null — nunca um número inventado.

ALWAYS-ON DISPLAY
AOD próprio, quase todo preto, que mantém o visual JSON com menos pixels acesos e sem segundos.

Feito em Watch Face Format para Wear OS 5+. Otimizado para Samsung Galaxy Watch 6 e telas AMOLED redondas.
