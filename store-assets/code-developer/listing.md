# Code Developer — store listing

## en-US

**Title (≤30):** Code Developer Watch Face

**Short description (≤80):** Go or JavaScript on your wrist. Editor themes, real data, AOD and presets.

**Full description:**

Time compiles. Code Developer renders your watch face as a real code editor — in Go or JavaScript — with the
current time as the star of the source file.

Go: dev := Dev{ Time: "14:35", Battery: 85, Steps: 8240, }
JavaScript: const dev = { time: "14:35", battery: 85, steps: 8240, };

PRESETS
• Go Developer and JavaScript Developer
• VS Code Dark — editor background, progress bars, complications
• Terminal — green phosphor, large text
• Minimal Code — just time and date
• Full Stats — every indicator with battery and step rings
• AMOLED — minimal lit pixels
Every preset is a starting point: change any option afterwards.

DEEP CUSTOMIZATION
• Switch between Go and JavaScript
• 11 syntax themes: VS Code Dark+, Dracula, Monokai, One Dark, GitHub Dark, Nord, Solarized, Gruvbox, Terminal,
  Amber CRT, Mono
• Line numbers, editor tab and status bar on/off
• Code text size & spacing, 5 layouts / code densities
• Time: phone setting, 24 h, 12 h, AM/PM, seconds, 4 clock sizes, 10 clock colors
• 10 date formats
• Battery and steps as numbers, bars, rings or icons; heart rate; weather in °C/°F
• Two complication lines for calories, distance or any data source on your watch
• 5 dark backgrounds

REAL DATA ONLY
Every value comes from the watch. Missing weather becomes nil / null in the code — never invented numbers.

ALWAYS-ON DISPLAY
A dedicated low-power AOD: black background, light font, no seconds, same editor identity.

Made with Watch Face Format for Wear OS 5+. Optimized for Samsung Galaxy Watch 6.
