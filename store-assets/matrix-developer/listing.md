## en-US

**Title (≤30):** Matrix Developer Watch Face

**Short description (≤80):** Green digital rain + terminal readout. Real data, AMOLED, AOD and presets.

**Full description:**

Digital rain. Real data. Matrix Developer wraps a glowing terminal clock in columns of falling green code — built
for AMOLED and tuned for battery life: the rain advances once per minute, with no continuous animation.

PRESETS
• Classic — balanced readout over binary rain
• Dark — deep green, faint hexadecimal rain
• Minimal — big clock and date
• Full Digital — every indicator, rings and complications
• AMOLED Green — no rain, minimal lit pixels
Start from a preset and change any option individually.

DEEP CUSTOMIZATION
• Rain density (off to high) and characters: binary, hexadecimal, digits, code symbols
• 11 main colors (6 greens plus cyan, amber, red, purple, white), highlight color, visual intensity
• Clock glow, decorative frame, 4 clock sizes, 12/24 h, AM/PM, seconds
• 10 date formats
• Battery and steps as numbers, bars, rings or icons; heart rate; weather with condition icons in °C/°F
• Two complication readouts for calories, distance or any data source on your watch
• 5 layouts: Minimal, Compact, Balanced, Full, Informative

REAL DATA ONLY
Readouts come from the watch. No weather source? You see NO SIGNAL — never a made-up value.

ALWAYS-ON DISPLAY
Rain and decorations switch off; a dim green clock stays readable on pure black.

Made with Watch Face Format for Wear OS 5+. Optimized for Samsung Galaxy Watch 6.
